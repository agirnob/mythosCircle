# References for the two-section worldbuilding flow

Reviewed 2026-10-18. These examples inform interaction patterns; the combined flow is a mythosCircle proposal, not a claim that another product ships the same workflow.

| Reference | Documented behavior | Proposed adaptation |
|---|---|---|
| [LegendKeeper Boards](https://dev.legendkeeper.com/boards-announcement/) | Page cards link existing wiki entries into boards; users can edit linked pages and connect them with arrows. | A persistent workspace grounded in real world entities. |
| [Kanka nested entries](https://docs.kanka.io/en/latest/features/nested.html) | Parent locations support nested browsing, with a flat view option. | A keyboard-readable outline to select a city and drill into its places. |
| [WorldSmith research](https://arxiv.org/abs/2308.13355) | Image-based worldbuilding using iterative layered edits and hierarchical compositions. | Develop one selected part at a time. Its image research does not establish NPC-generation correctness. |
| [NovelAI Lorebook](https://docs.novelai.net/en/text/lorebook/) | Relevant lore entries can enter AI generation context. | Use selected world facts and connections as expansion context. |

The owner authorized a visual exploration after reviewing these patterns. Familiar Guided Build precedes actual world content; planning is an ongoing expansion activity. Layout approval and backend implementation remain outstanding.
