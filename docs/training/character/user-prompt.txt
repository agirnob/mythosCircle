- debt: any -> any
- employs: character|faction|place -> character|faction — X employs, commands, or retains Y — a city may employ its watch-captain; places are never employees
- enemy_of: any -> any
- grudge: any -> any
- hails_from: character|faction -> place — X's origin or home district — where X comes from, not where X is now
- kin_of: any -> any
- located_in: any -> place — X is physically inside Y — a place's floor, walls, or waters
- loyalty: character|faction -> character|faction — a place holds and receives no loyalty

- relationship: any -> any — LAST RESORT — prefer the specific type that fits
- rival_of: any -> any
- worships: character|faction -> character|faction — X serves or reveres Y — faith, cult, devotion; a place is never a worshipper or worshipped
