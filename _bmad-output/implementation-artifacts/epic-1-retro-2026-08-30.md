### Duplication map — six clusters

1. **Two cursor-pagination engines, divergent miss semantics.** jobs `_after_rowid` (store/jobs.py:466) silently resets to page 1 on an unknown cursor ULID; campaigns `list_campaigns` (store/campaigns.py:92-110) raises 422. Same `limit+1/has_more/next_cursor=page[-1].id` scaffold duplicated in both. — fix-now (converge + share scaffold)
2. **Split error taxonomy.** Every store module subclasses `StoreError` (commit.py:97, jobs.py:23-71, auth.py:47) EXCEPT campaigns (InvalidThemeError/ValueError, campaigns.py:40); `api/campaigns.py` catches `(InvalidThemeError, ValueError)` inline (l105) instead of a shared mapper (api/jobs.py `_store_error_as_http` l72). Wire codes consistent (422/404). — fix-now (campaigns → StoreError)
3. **Env-parse helpers + constants duplicated.** `core/settings.py _env_non_negative_int/_env_positive_float` (l49,108) vs `core/config.py _env_int/_env_float/_config_int/_config_float` (l85,97,109,120); same env keys (`MAX_PENDING_PER_CAMPAIGN`==`MAX_PENDING_ENV`, etc.) and same defaults (10, http://127.0.0.1:8080/v1, 120) defined twice. — defer (consolidate in refactor)
4. **Crockford-ULID predicate triplicated.** `commit._check_ulid` (l365), `jobs._check_ulid` (l438, self-cites "like commit._check_ulid" — a copy), `pagination.decode_cursor` (l20,37). Same body, three error classes. — fix-now (single `core/ids.is_valid_ulid`)
5. **Default themes in three copies + dead fallback.** `config.DEFAULT_THEMES` (core/config.py:35), `campaigns.SEED_THEMES` (store/campaigns.py:27) — but `configured_seed_themes()` (l30-35) checks `if configured:` which is ALWAYS truthy (config falls back to DEFAULT_THEMES), so `SEED_THEMES` is **unreachable dead code** — plus `deploy/config.toml [campaigns].themes`. — fix-now (one canonical seed, config = code)
6. **Correct centralization:** `core/time.py` + `core/ids.py` single sources; no stray datetime/UUID. — pass
