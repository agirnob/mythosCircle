## 3. Bugs found and fixed during resume (all in the commits)

- `common.py` 422 mapping was missing the new v3 rejections → null-prose
  POSTs 500'd. Added BlankEdgeReasonError / EdgeKindViolationError /
  InvalidRunStateError.
- `GET /kinds` was registered AFTER the `/{campaign_id}` catch-all (always
  404 — a literal path can't win in FastAPI order) and its payload
  comprehension referenced `src`/`dst` never bound (never ran until the
  move). Route moved above the catch-all; unpacking fixed.
- Regenerate payload gates used `set(payload) > allowed` — an inverted
  superset check that silently passed unknown keys once the allowed set
  grew to 4 keys. Fixed with set-difference in `jobs.py` + `regenerate.py`.
- `_fill_blank_reasons` passed `max_tokens=` as a provider kwarg (breaks
  every `(prompt, settings)` mock) — moved into `dataclasses.replace`.
- PATCH edge response echoed the stale stored reason instead of a fresh
  supplied one.
- **`login_session` migration ordering flaw**: `create_all` ran before the
  rename, so a pre-v3 DB gained an empty `login_session` and the old
  `session` table was orphaned — first v3 startup would log everyone out.
  Fixed with a both-tables merge branch (INSERT..SELECT + DROP); migration
  tests cover rename / merge / edge.reason-NULL shapes.
