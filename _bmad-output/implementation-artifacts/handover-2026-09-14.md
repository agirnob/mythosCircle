### The spec's shape (frozen intent, review-hardened)

- `format=maptool` → `{stem}.rptok` download; deterministic ZIP (fixed
  member timestamps, pinned compress_type, no extra fields, stable order).
- Token id derived: `base64(sha256(entity_id)[:16])` in
  `<id><baGUID>…</baGUID></id>` — NOT 32-hex (review loop 0 corrected this
  against the owner's real file).
- `notes` = 2024-Core stat-block grammar text + race/alignment header;
  `gmNotes` = AR24 lore verbatim; `notesType`/`gmNotesType` = `text/plain`.
- Portrait rides the `imageAssetMap` null-key only (owner's export has no
  `<portraitImage>`); asset = `assets/<md5>` descriptor + `<md5>.png`
  (MD5 of bytes, FIPS-safe); broken portrait → no image fields + `[missing]`
  marker in notes.
- `tokenType=NPC` always (enum is only PC/NPC); no validation in export
  (FR18); 404/422 shapes identical to the fg path.
- **Ask-First deferrals (open decisions for elicitation):** (1) emit
  attack/spell macros into `macroPropertiesMap` — persists through import
  (owner's file proves it) — needs derived macro UUIDs + command-grammar
  decision (bare `[4d6+5]` vs `!tokenprop` hit-check); (2) emit structured
  stats into `propertyMapCI` (persists; display is campaign-dependent);
  (3) `notesType` `text/html`; (4) thumbnails/charsheetImage; (5) installing
  Java + MapTool on the dev box (`java` absent) for the formal gold + live
  round-trip, vs the owner producing it on their machine.

- **Wire contract:** `GET /api/campaigns/{id}/entities/{eid}/export?format=fg`
  → `{label}-{id}.xml` (`text/xml` attachment), the FG Unity 5E **2024 NPC
  record** — the exact shape FG's own Export NPC writes. DM: **NPCs →
  Import** (file picker). Proven end-to-end: the owner imported the staged
  sample into FG Unity and re-exported it; every emitted field survived
  typed correctly (fixture `fixture-fg-npc-record-2024-import-roundtrip.xml`).
- **Field mapping (verified, fixture-pinned):** name/type/alignment as
  strings; `ac`/`hp` numbers (+ long keys `armor_class`/`hit_points`);
  `cr` as STRING from `identity` numerics (NPC/BBEG level, Monster
  fraction→decimal); `abilities.<attr>.{score,savemodifier}` (save − mod,
  the importer's derivation); `initiative.misc` = init − dex mod; skills
  join with sign; traits/actions as `npc_power` (`name`+`desc`, enumerated
  `id-0000N`); spells as names; `version` 2024; sparse-legal everywhere.
- **`text` notes = the AR24 lore** (owner ruling): appearance, personality,
  background, goals, relationships, secret, rumor, party_hook, voice_style,
  catchphrases — labelled paragraphs in AR24 order, verbatim; empty notes
  still emit `<p />` (FG's own shape). Stat block lives in FG's structured
  fields; the 2024-Core stat-block text builder was deleted (no Import-Text
  paste source in the artifact — paste text comes from Markdown/HTML
  exports if ever wanted).
- **Portrait:** FG image fields are embedded bitmaps — the artifact names
  the newest available file (`Information: Portrait: <filename>` /
  `[missing]`); the live signed URL comes from the existing
  `portrait-url` route (7-day TTL, determinism-safe — a metal URL would
  break byte-identical repeats).
